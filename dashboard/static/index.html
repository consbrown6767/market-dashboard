How it works

The idea: when a big stock breaks above its call wall and holds, dealer hedging pushes it further up. This makes predictions and checks them. It never trades.
Prediction needs all three: a 5-minute bar closes above the call wall; none of the next six bars closes below it (30-minute hold); volume so far today is more than 1.5× normal for that time of day.
Score, one point each: sector ETF above its open and previous close; price above the gamma flip; crowded shorts (no free data yet, so this point is never earned). Score 1 is a prediction, 2 or more is strong, 0 is no prediction.
Grading: checked at that day's close, the next close and three closes later. A prediction is wrong if any 5-minute bar closes back below the wall before the check. Every breakout is logged, including failures: they're what predictions get compared against.
Keep in mind: walls and the flip are estimates. Open interest doesn't show which side dealers are on; the flip assumes they're short calls and long puts. Common theory says dealers dampen moves above the flip, so that point may point the wrong way, and the log will settle it. Bars run about 16 minutes behind on the free plan: fine for checking predictions, not for trading. Levels use yesterday's closing open interest and the last option snapshot before today.
Replay days ran the same rules on past days after the fact, using what was known at the time. They're kept apart from the live forward test.

How scoring works

Written down first: a prediction is stamped when it's logged and refused if its window has already opened. No hindsight.
Never edited: each live prediction is chained to the one before it, so a changed or deleted row fails the check. A retuned model is a new version with its own score.
Always next to a simple guess: every prediction carries a baseline made at the same moment, scored the same way. A model is only worth keeping if it beats it.
Scores: chances use the Brier score (saying 50% every time scores 0.25; lower is better). Ranges use the quantile loss, which punishes both missing and being too wide. "Smaller error" compares the two averages.
Live and backtest apart: backtests rerun a model on past days with only what was known then. They can be rerun, so they're shown separately and never mixed into live results.
